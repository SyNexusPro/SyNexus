# Internationalization (i18n)

SyNexus localizes UI chrome and makes **Titan reply in any selected language**.

## How it works

| Layer | Behavior |
|-------|----------|
| **Language picker** | Bottom-left control — search 80+ languages |
| **UI packs** | Full chrome translations for majors (en, es, fr, de, pt, zh-CN/TW, ja, ko, ar, hi, ru, id, vi, tr, it, nl, pl, uk, th, he, …) |
| **Any other language** | UI falls back to English; **Titan still answers in that language** |
| **Auto** | Uses device `navigator.language` |
| **RTL** | `ar` / `he` / `fa` / `ur` set `dir="rtl"` |

Storage key: `synexus_locale`

## Add a UI pack

1. Add strings to `src/i18n/catalogs.ts` via `catalog({ ... })`.
2. Prefer the same keys as `src/i18n/en.ts`.
3. Wire more pages with `useTranslation()` + `t("key")`.

## Titan

`replyLanguage` is sent on `/api/titan/chat` and enforced in the system prompt.
